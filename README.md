# 🎨 Projeto Portfolio B2B — 3º Ano EMTI Profissional 2026

Este repositório reúne os projetos desenvolvidos pelos alunos do **3º Ano do Curso Técnico em Informática** do EMTI Profissional, na disciplina de **Laboratório Web**.

A atividade teve como objetivo **refazer/simular, por meio de código, a interface do projeto Portfolio B2B**, utilizando o projeto original como referência.

🔗 **Projeto original:** [Portfolio B2B](https://prof-ana-ferreira.github.io/portfolio-b2b/)

---

## 📋 Sobre o Projeto

Cada aluno desenvolveu sua própria versão da interface do **Portfolio B2B**, buscando reproduzir a estrutura visual e os principais elementos presentes no projeto original.

Durante a atividade, foram trabalhados conceitos de:

- Hierarquia visual
- Tipografia
- Cores e identidade visual
- Organização e composição de elementos
- Layout e espaçamento
- Estruturação de páginas web
- HTML e CSS
- Responsividade
- Usabilidade e experiência do usuário (UX/UI)

O objetivo foi **analisar uma interface existente e reproduzi-la utilizando código**, desenvolvendo a percepção visual e a capacidade de transformar uma referência de design em uma página web funcional.

---

## 🎨 Projeto de Referência

O projeto utilizado como referência apresenta uma interface de uma plataforma fictícia voltada ao público B2B.

A página possui diferentes seções, incluindo:

- Hero / apresentação principal
- Empresas e parceiros
- Seção de descoberta
- Ferramentas e recursos
- Clientes e depoimentos
- Velocidade e desempenho
- Eventos
- Rodapé
